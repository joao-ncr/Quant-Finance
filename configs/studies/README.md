# Estudos pré-registrados

Cada estudo com dados reais terá aqui um arquivo de pré-registro versionado (Etapa 5 do pedido de implementação / Etapa 10 do roadmap): hipótese, universo, liquidez, grade, métricas, períodos, nº de simulações e limiares. Alterações geram nova versão com justificativa; nunca se sobrescreve um pré-registro já usado. Vazio até que as decisões DE/DD necessárias estejam `DECIDED`.
